# 📊 MarketFlash Marketing Analytics Project

A marketing analytics project focused on transforming campaign data into a structured relational database and actionable business insights using **SQL, data modeling, Excel, and Tableau**.

## 🎯 Project Overview

MarketFlash is a marketing analytics project designed to analyze campaign performance and help stakeholders understand how different campaigns are performing across key business metrics.

The project covers the complete analytical workflow — from understanding the source data and designing a relational database to querying the data and preparing it for business intelligence and visualization.

## 💡 Business Objectives

The project aims to answer questions such as:

* Which marketing campaigns perform best?
* How much does each campaign cost?
* Which campaigns generate the strongest conversions?
* What is the average cost per click?
* What is the average cost per conversion?
* How do campaign performance and ROI differ across campaigns?
* Which areas could benefit from optimization?

## 🔎 Project Approach

### 1. Data Understanding

Reviewed the marketing campaign dataset to understand:

* Campaign attributes
* Performance metrics
* Cost information
* Clicks and conversions
* Campaign-level business measures

### 2. Data Modeling

Designed a structured relational database to organize the marketing data.

The repository includes:

* Entity Relationship Diagram
* Functional ER Diagram
* Database schema
* SQL challenges and queries

This provides a structured foundation for analysis and reporting.

### 3. SQL Analysis

Used SQL to:

* Query campaign performance
* Aggregate marketing metrics
* Calculate business KPIs
* Compare campaign performance
* Prepare data for visualization

### 4. Business Intelligence

Prepared the processed data for Tableau analysis and dashboard development.

Key metrics include:

* Average Cost per Click
* Average Cost per Conversion
* Campaign Performance
* Conversion Performance
* Marketing Cost
* ROI-related metrics
